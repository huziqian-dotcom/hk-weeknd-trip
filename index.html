机场 → 市区 / 场馆

  1. 机场快线 Airport Express
    香港国际机场 → 青衣 →（东涌线转）南昌 →（屯马线）宋皇台 / 启德。旅发局估算约 1 小时 5 分。可用八达通。
  2. 巴士（省钱）
    城巴等机场路线可到九龙城一带，再步行或转短程；班次与票价请查城巴 / KMB 或 Trip.com 机场指引。
  3. 的士
    市区的士（红的）直达；说明「啟德主場館 / Kai Tak Stadium」。车费较高，适合行李多或赶时间。

实用贴士

八达通
地铁、巴士、部分便利店通用；机场也可买/加值。游客版八达通可在机场或客服购买。
AlipayHK / WeChat Pay HK
许多商户收；内地支付宝/微信到港后常需开通香港版或绑定支持卡，出发前在 App 内确认，勿假设一定能刷。
插头
香港为英式 Type G 三脚方插，电压 220V。马来西亚多为 Type G，多数插头可直接用；仍建议带一条万能转换以防万一。
天气
开演前查香港天文台：https://www.hko.gov.hk/ 长伞可能不准带入场，带短折伞或轻便雨衣。
